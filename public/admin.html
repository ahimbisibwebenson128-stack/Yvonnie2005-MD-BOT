Frequently asked questions

Owner help centre

Where do I connect WhatsApp?

Open the Connection Portal. Enter the configured owner number and private access key. You can request a pairing code or display the QR code and scan it from Linked Devices.

Why is the AI showing as not configured?

The Gemini API key must be present in the private Render environment or bot database. Never add the key to this ZIP or commit it to GitHub.

Why do some settings need a restart?

Some settings are read when command handlers are registered during startup. The dashboard tells you when a restart may be needed.

Why can't the dashboard promise every command works?

Some commands depend on WhatsApp group permissions, FFmpeg, yt-dlp, third-party API availability, valid credentials and network access. The catalogue shows registered commands; live behaviour must be tested against the connected WhatsApp account.

How do I view logs?

Open your existing Render service dashboard and inspect the latest deploy and runtime logs. This dashboard does not fabricate logs.

Will my settings survive a redeploy?

Dashboard settings are saved in the configured database. Keep the existing Render database and its environment variables when deploying the ZIP.
